\# CODSOFT Internship Tasks



A collection of backend development projects completed as part of the CODSOFT Internship.



\## Projects



\### 1. Student Record Management System API

\- Node.js, Express.js, MySQL

\- Student, Course and Enrollment CRUD APIs

\- Validation and pagination



\### 2. Contact Management System

\- Node.js, Express.js, MySQL

\- Contact CRUD, search, sorting and pagination

\- Duplicate validation



\### 3. To-Do List Backend

\- Node.js, Express.js

\- REST API for task management



\### 4. Online Quiz System

\- Node.js, Express.js, MySQL

\- JWT authentication and bcrypt

\- Quiz management, automatic scoring, result history and leaderboard



\## Technology Stack

\- Node.js and Express.js

\- JavaScript (ES6+)

\- MySQL

\- REST APIs and JWT

\- Git and GitHub

\- Jest and Supertest
